🔍 Uji CORS — Gerbang Tahap 0

Menentukan apakah frontend GitHub Pages boleh memanggil Apps Script langsung, atau perlu Cloudflare Worker.

Yang diuji: apakah JavaScript di halaman ini bisa membaca isi respons JSON dari Apps Script lintas origin. Jika hasilnya CORS block / Failed to fetch, berarti GitHub Pages tidak bisa memanggil Apps Script langsung dan arsitektur harus menggunakan proxy (Cloudflare Worker).

Penting: halaman ini harus sudah ter-host di GitHub Pages (bukan file:///) agar origin-nya benar.
